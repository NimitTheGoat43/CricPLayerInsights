# 🏏 CricPlayerInsights

A Flask-based Cricket Analytics & Intelligence Platform that provides comprehensive IPL player analysis using data analytics, interactive visualizations, and performance insights.

---

## 📌 Project Overview

CricPlayerInsights is designed to analyze historical IPL ball-by-ball data and provide meaningful insights into player and team performances. The platform enables users to explore batting, bowling, comparison, and statistical analysis through an interactive web application.

---

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/CricPlayerInsights.git
```

### Open Project

```bash
cd CricPlayerInsights
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```

Visit:

```
http://127.0.0.1:5000
```
